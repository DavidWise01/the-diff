# THE DIFF

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **THE TRANSCRIBER**.

THE DIFF — THE TRANSCRIBER: when two versions of a text differ, what actually changed? Find the LONGEST run of characters they still share in order — the longest common subsequence — and everything outside it is an addition or a deletion. Every ‘diff’ you have ever seen is this. ⚑ LIVE full-house instrument: two strings with the kept common thread lit teal and the changed characters copper, across several text pairs; the common thread in 3D; tesseract 4D + shadow + toddler. ◆ LIT: d[i][j]=d[i−1][j−1]+1 on a match else the better of dropping either side; traceback yields the characters both keep in order; a fail-loud self-check throws unless the recovered LCS is a genuine subsequence of BOTH strings and has the optimal length. ▲ AMBER: character-level here (real diffs work on lines with Myers/patience heuristics); the LCS and its subsequence property are exact. The skeleton of every version-control diff. Node-verified. David Lee Wise / ROOT0, with AVAN.
